# Bird-QK Gate 3 Unity bootstrap

The source package is stored as SHA-256-pinned base64 chunks. Submit to UMass Unity with:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Ehsan-Roohi/DSMC_Python/main/qk_gate3_bundle/submit_qk_gate3_unity.sh)
```

The script reconstructs `qk_gate3_shock_induction`, verifies the archive checksum, and submits an 8-seed, 4-CPU validation job.
